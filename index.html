        Etch history
        
Local list of etches made on this device. Newest first.

        

        

          
          
        

      


      

        Bootstrap peers
        
One peer per line. Format: ip:port or full multiaddr. Leave empty to use the default Autonomi mainnet list. Saving reconnects.

        
        

          
          
          
        

      


      

        Library indexer
        
Etherscan-V1-compatible base URL. Default is keyless BlockScout.

        
        

          
          
        

      


      

        Library key — backup / restore
        
The 32-byte AES key derived from your wallet. Shared across mobile + desktop + web viewer for the same wallet. Anyone with this key plus your wallet address can read your library.

        

          
          
          
        

        

      


      

        Decode library with a manually-entered key
        
Fallback for when a wallet sign isn't available — paste the wallet address and 64-hex library key directly.
