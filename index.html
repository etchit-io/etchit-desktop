      Settings i

      

        Etch history i
        
Local list of etches made on this device. Newest first.

        

        

          
          
        

      


      

        Back up private etches i
        

          Encrypts your private etch list with a passphrase, then etches it to the network for cross-device recovery (or download as a file). One passphrase per wallet — set it once, write it down, every future backup reuses it automatically.
        


        
        

          

            Recovery passphrase set for this wallet. New backups encrypt with the same passphrase you wrote down.

            recommended — 6 BIP-39 words, ~66 bits entropy
          

          
          
          

          
          
          
        


        

          
          
          
        

        

      


      

        Restore private etches from a backup i
        
From a previous backup made with the same password — either etched to the network (paste the address) or saved to a file (pick the file).

        
        
        

          
        

        
        

          
          
          
        

        
        

        

          
        

      


      

        Chainmark key — backup / restore i
        
The 32-byte AES key derived from your wallet. Shared across mobile + desktop + web viewer for the same wallet. Anyone with this key plus your wallet address can read your chainmarks.

        

          
          
          
        

        

      


      

        Decode chain/it with a manually-entered key i
        
Fallback for when a wallet sign isn't available — paste the wallet address and 64-hex chainmark key directly.

        
        

        
        

          
          
        

        

          
        

      




       

        Bootstrap peers i
        
One peer per line. Format: ip:port or full multiaddr. Leave empty to use the default Autonomi mainnet list. Saving reconnects.

        
        

          
          
          
        

      


      

        Chainmark indexer i
        
Etherscan-V1-compatible base URL. Default is keyless BlockScout.
